# Personal Expense Tracker with Shared Expense Fairness Detection

## Project Overview
The Personal Expense Tracker is a C++ application developed using Object-Oriented Programming concepts. It helps users manage personal expenses and shared group expenses.

## Features
1. Add Personal Expense
2. View Personal Expenses
3. Personal Spending Summary
4. Add Shared Expense
5. View Shared Expenses
6. Calculate Member Balances
7. Shared Expense Fairness Report

## Unique Feature
**Shared Expense Fairness Detector**

This feature calculates how much each group member should pay or receive based on equally divided expenses. It helps identify pending payments and maintain fairness among group members.

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Constructors
- Data Members and Member Functions
- Vectors
- File Handling

## Technologies Used
- Programming Language: C++
- Compiler: GCC / MinGW
- Standard: C++17

## How to Run

Compile the program:

```bash
g++ -std=c++17 main.cpp -o expense_tracker
```

Run on Windows:

```bash
.\expense_tracker.exe
```

Run on Linux/macOS:

```bash
./expense_tracker
```
